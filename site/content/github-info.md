## Recent updates worth knowing

- **Refreshed pull requests page is now generally available.** The redesigned repository pull requests list makes it easier to scan status and reviewers at a glance. (Source: [GitHub Changelog](https://github.blog/changelog/2026-09-21-refreshed-repository-pull-requests-page-generally-available))
- **Copilot code review has an improved review experience.** Recent UX changes make Copilot's automated code review comments easier to read and act on. (Source: [GitHub Changelog](https://github.blog/changelog/2026-09-18-copilot-code-review-an-improved-review-experience))
- **GitHub Copilot app basics for beginners.** A walkthrough of viewing diffs, running terminal commands, and previewing web apps directly in the Copilot app — a good primer for new Copilot users. (Source: [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-using-the-diff-terminal-and-browser/))
- **Awesome Copilot has ready-made agentic workflows to learn from.** Examples like the "Relevance Check" workflow (a `/relevance-check` slash command that flags stale issues and PRs) show practical patterns for automating repository maintenance with Copilot. (Source: [Awesome Copilot workflows](https://github.com/github/awesome-copilot/blob/main/workflows/relevance-check.md))
